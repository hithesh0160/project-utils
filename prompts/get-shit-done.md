# Get Shit Done Prompts

## Turn Mess Into A Plan

```text
I have a messy set of tasks. Help me turn this into a Get Shit Done plan.

First, identify the real outcome. Then split everything into do, defer, delegate, and delete. Give me a short ordered plan with the first action small enough to start in 5 minutes.

Raw notes:
<paste notes>
```

## Find The Next Action

```text
I am stuck on this goal:
<goal>

Ask only the questions needed to find the next useful action. Then give me one tiny first move, one focused work block, and one verification step.
```

## Finish The Last 20 Percent

```text
This project is mostly done but not shipped:
<project state>

Identify the remaining work, cut anything nonessential, and give me a finish plan that gets this shipped. Include verification and a short final handoff summary.
```

## Daily Focus

```text
Help me plan today using a Get Shit Done format.

Context:
<calendar, obligations, deadlines, energy level>

Give me:
- today's outcome
- top 3 tasks
- first 5-minute action
- likely blockers
- closeout checklist
```

## AI Coding Agent Brief

```text
Convert this goal into a clear coding-agent brief.

Goal:
<goal>

Include:
- desired outcome
- files or areas likely involved
- constraints
- verification steps
- what should not be changed
- final response expectations
```
