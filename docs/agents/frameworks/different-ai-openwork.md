# OpenWork (`different-ai/openwork`)

[OpenWork](https://github.com/different-ai/openwork) (by [Different AI](https://github.com/different-ai)) is an open-source, local-first desktop application and agent workspace (functioning as an open-source alternative to Claude Cowork / Claude Code UI).

---

## Key Features

- **Local-First & Desktop Native:** Cross-platform desktop interface (macOS, Windows, Linux) built on OpenCode technology.
- **Model Context Protocol (MCP) Integration:** Direct connectivity with MCP tools, local filesystems, shell runners, and external integrations.
- **Multi-Session Management:** Simultaneous agent runs with live terminal output, artifact previews, and execution history.
- **Skill Engine & Hub:** Capture, import, and share reusable workflows and skills via OpenWork Hub.
- **Subagent & Multi-Model Orchestration:** Route sub-tasks across local LLMs (Ollama) or cloud providers (Claude, OpenAI, Gemini).

---

## Ecosystem

- **`different-ai/openwork`**: Main desktop application repository.
- **`different-ai/openwork-hub`**: Community hub for sharing skills, agent templates, and custom MCP connectors.
