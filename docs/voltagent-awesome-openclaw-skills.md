# Awesome OpenClaw Skills (`VoltAgent/awesome-openclaw-skills`)

[Awesome OpenClaw Skills](https://github.com/VoltAgent/awesome-openclaw-skills) (by [VoltAgent](https://voltagent.dev/)) is a curated index of over 5,000+ skills and integrations designed for autonomous AI agents using OpenClaw (formerly Moltbot/Clawdbot).

---

## Purpose & Scope

The OpenClaw/ClawHub ecosystem allows AI agents to load custom tools ("skills") for browser automation, CLI tasks, devops, database management, social media interaction, and API calls. `VoltAgent/awesome-openclaw-skills` acts as a quality-filtered, anti-spam directory of verified skills.

---

## Key Categories

- **Coding & IDEs:** Multi-language linters, code execution sandboxes, refactoring tools, and AST search plugins.
- **DevOps & Cloud:** Kubernetes controllers, Docker runners, Terraform helpers, AWS/GCP/Azure CLI tools.
- **Web & API Integration:** Web scrapers, GitHub API tools, Slack/Discord bots, email automation, and headless browser triggers.
- **Data & Databases:** SQL generators, vector database connectors, schema migrators, and RAG pipelines.

---

## Installation & Usage

Skills are fetched and installed into your local agent environment using the ClawHub CLI:

```bash
# Install a specific skill from the directory
npx clawhub@latest install <skill-name>
```
