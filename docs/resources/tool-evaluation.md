# Tool Evaluation Checklist

Use this checklist before adding a new utility to your regular project workflow.

## Fit

- What project problem does this solve?
- Is the problem frequent enough to justify another tool?
- Does it replace an existing workflow or complement it?
- Does it work across multiple projects?

## Setup

- How long does first setup take?
- Are credentials, API keys, or local services required?
- Can it run offline?
- Does it require generated files to be committed?

## Output Quality

- Is the output accurate enough to trust?
- Does it cite files, lines, commands, or evidence?
- Can incorrect output be detected quickly?
- Does it produce stable results across repeated runs?

## Maintenance

- How is the output updated?
- What files should be ignored?
- What files should be committed?
- Who owns keeping the tool notes current?
