# FreeDomain (`DigitalPlatDev/FreeDomain`)

[FreeDomain](https://github.com/DigitalPlatDev/FreeDomain) (by [DigitalPlat](https://digitalplat.org)) is an open-source initiative providing free domain names and DNS management resources for developers, students, open-source projects, and non-profits.

---

## Key Features

- **Free Subdomain Extensions:** Provides free domain registrations across extensions such as `.dpdns.org`, `.us.kg`, `.qzz.io`, `.xx.kg`, and `.qd.je`.
- **Custom DNS Provider Support:** Supports binding registered free domains to third-party DNS servers including Cloudflare, FreeDNS, and Hostry.
- **Full Records Management:** Allows configuration of `A`, `AAAA`, `CNAME`, `TXT`, `MX`, and `NS` records.
- **Open-Source Infrastructure:** Frontend and management dashboard codebase hosted under `DigitalPlatDev/Domain-OSS` (AGPL-3.0).

---

## How to Register & Manage

1. **Dashboard:** Access the management console at [dash.domain.digitalplat.org](https://dash.domain.digitalplat.org/).
2. **Account Creation:** Register an account using email or GitHub OAuth.
3. **Domain Binding:** Select your desired extension, enter DNS nameservers (e.g. Cloudflare `ada.ns.cloudflare.com`), and confirm.
